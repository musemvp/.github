# .github

Public configuration repository for the MuseMVP organization.

- `profile/README.md`: the profile shown on the organization home page.
- `profile/assets/`: brand files used by that profile.
  - `hero.webp`: title page on the site's paper ground `#F4F0E6`. Wordmark, the line "Build a web app in hours.", and three columns for Starter, Workers, and the collection. Ink `#241E19`, copper rule `#C4A574`.
  - `musemvp-wordmark-light.svg` / `musemvp-wordmark-dark.svg`: wordmark for dark and light grounds, outlined from Fraunces Semibold. Change the typeface at the source, then export again.
  - `musemvp-mark.svg`: product mark, cream `#F6F1E8` and copper `#F0A030`, traced from the product icon.

The logo, wordmark, and other brand assets are for official MuseMVP use. This repository does not release them under an open-source license.
